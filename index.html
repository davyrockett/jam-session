How to get an access key

Easiest: add this project to the key you already use for Health Log or Z4 Log, then paste that same key here.

  1. On github.com go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Open your existing sync key and tap Edit.
  3. Under Repository access, add jam-session-data, then save.

Or make a new key: Generate new token, name it "Jam Session sync", choose Only select repositories → jam-session-data, and set Repository permissions → Contents to Read and write.
